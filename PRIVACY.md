# Privacy

The Gorptastic 0.1.0 package has no hosted service, account integration, telemetry, or network-enabled helper. Its Python helper reads only the input JSON and source files selected by the caller. It writes a bundle only to the output path supplied by the caller. Source-file contents and absolute source roots are not embedded in that bundle; the caller's card text and relative artifact names are included.

The skill runs inside your chosen assistant. The assistant and any research tools it uses have their own data handling policies. This package does not change those policies. Do not send private material to a research tool or publish it without the appropriate authorization.

GitHub issues, pull requests, and release downloads are handled by GitHub. Public contributions can be read by anyone. This plugin has no automatic submission action. Review the material before posting, including filenames, URLs, and metadata.

For a privacy concern, use the repository's support page without repeating sensitive information. For accidentally posted secrets, use GitHub's reporting and removal tools and rotate affected credentials.
